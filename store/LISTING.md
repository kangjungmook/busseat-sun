# 플레이 콘솔 등록 정보

콘솔에 그대로 붙여넣을 수 있게 적어둡니다. **내용은 앱이 실제로 하는 것에
맞췄습니다** — 데이터 안전 섹션이 개인정보처리방침과 어긋나면 반려됩니다.

## 앱 이름 (30자 이내)

```
햇살좌석 - 버스 그늘 좌석 찾기
```

## 간단한 설명 (80자 이내)

```
버스 타기 직전 3초. 태양 위치와 노선 방향을 계산해 어느 쪽 창가가 그늘인지 알려드려요.
```

## 자세한 설명 (4000자 이내)

```
버스에 올라 아무 창가에나 앉았다가 30분 내내 햇볕을 맞아본 적 있나요?

한 번 앉으면 옮기기 어렵습니다. 자리를 잡고 나서 아는 건 늦습니다.
햇살좌석은 타기 전에 딱 하나만 답합니다. 왼쪽이냐, 오른쪽이냐.

■ 이럴 때 씁니다

· 폰이 안 보일 때
  직사광이 화면에 닿으면 밝기를 최대로 올려도 안 보입니다. 배터리만 닳고,
  손으로 가리며 버티게 됩니다.

· 눈이 부실 때
  창밖도 폰도 제대로 못 보고, 내릴 정류장을 놓치기도 합니다.

· 여름
  에어컨이 나와도 직사광이 닿는 자리는 체감이 다릅니다. 팔이 따갑고,
  한쪽만 땀이 납니다.

· 겨울
  반대로 볕 드는 자리를 찾습니다. 햇살 모드로 바꾸면 따뜻한 쪽을
  알려드려요.

· 자면서 가고 싶을 때
  얼굴에 해가 드는 자리에서는 눈을 감아도 계속 밝습니다.

· 아이와 함께 탈 때
  아이 얼굴에 직사광이 닿는 자리는 피하고 싶습니다.

· 노트북이나 책을 보는 장거리 구간
  광역버스처럼 한 시간 넘게 가는 노선에서 차이가 가장 큽니다.

· 멀미가 있을 때
  눈부심이 겹치면 더 힘듭니다.

■ 어떻게 답을 내나요

버스 좌석의 햇빛은 두 가지로 정해집니다. 버스가 어느 방향으로 달리는지, 그리고
그 시각 해가 어디에 있는지.

· 노선의 경유 정류장 좌표를 받아 구간마다 실제 진행 방위를 계산합니다
· 그 시각 그 위치의 태양 방위와 고도를 천문 계산식(NOAA)으로 구합니다
· 구간별 측면 일사를 거리로 가중해 좌·우를 정합니다

노선이 중간에 꺾여도 구간마다 따로 계산하므로, 기점과 종점을 잇는 직선 하나로
판단하지 않습니다.

■ 이런 것도 보여줍니다

· 구간별 일사 — 어느 구간이 그늘이고 어느 구간에 볕이 드는지
· 좌석별 그늘 지도 — 몇 열 어느 쪽이 좋은지
· 승차·하차 정류장 지정 — 내가 타는 구간만 계산
· AR 화면 — 카메라로 지금 햇빛이 드는 각도를 겹쳐 보기
· 즐겨찾기 — 자주 타는 노선을 3초 만에

■ 지원 지역

국토교통부 TAGO가 제공하는 138개 시·군의 시내버스를 지원합니다.
서울특별시는 아직 지원하지 않습니다(서울시가 별도 시스템을 운영합니다).
강원도는 춘천·원주·횡성·태백·홍천·철원·양양만 제공됩니다.

■ 솔직하게 밝혀둡니다

· 여기서 말하는 '그늘'은 태양이 반대쪽에 있어 그 창으로 직사광이 들어오지
  않는다는 뜻입니다. 건물 그림자는 반영하지 않습니다.
· 소요시간은 정류장 수 기반 추정치입니다(노선 API가 제공하지 않습니다).
· 좌석 배치도는 일반적인 24석 기준이며 실제 차량과 다를 수 있습니다.

■ 개인정보

자체 서버를 운영하지 않습니다. 위치는 가까운 정류장을 찾고 태양 위치를 계산하는
데만 쓰이며 저장하지 않습니다. 광고·분석 SDK를 넣지 않았습니다.
로그인은 선택이며, 로그인하지 않아도 모든 기능을 쓸 수 있습니다.

데이터 출처: 국토교통부(TAGO) 버스노선정보·버스정류소정보, 카카오 로컬
```

## 등록 자산

| 항목 | 규격 | 파일 |
|---|---|---|
| 앱 아이콘 | 512x512 PNG, 투명도 없음 | `store/play-icon-512.png` |
| 그래픽 이미지 | 1024x500 PNG/JPEG | `store/play-feature-1024x500.png` |
| 휴대전화 스크린샷 | 최소 2장, 세로 1080x2340 권장 | **직접 촬영 필요 — 아래 참고** |

**스크린샷은 실제 기기에서 찍어야 합니다.** 웹 미리보기 화면에는 '웹
미리보기라 검색이 꺼져 있어요' 배너와 '예시' 표시가 들어가 있어서, 그걸 올리면
실제 앱이 아닌 것을 보여주게 됩니다. 기기에서 실제 노선을 검색한 뒤:

1. 결과 화면 (왼쪽/오른쪽 창가 추천)
2. 좌석별 그늘 지도
3. 홈 화면 (태양 궤적)
4. 구간 지정 화면

네 장이면 충분합니다. 안드로이드 기본 스크린샷이 보통 1080x2340이라 그대로
올리면 됩니다.

## 데이터 안전 (Data safety) 섹션

개인정보처리방침(`web/privacy.html`)과 **반드시 일치해야** 합니다.

| 질문 | 답 |
|---|---|
| 데이터를 수집하거나 공유하나요? | **예** (제3자 API로 전송됨) |
| 위치 — 대략적/정확한 위치 | **수집 안 함, 공유함**<br>목적: 앱 기능. 전송처: 국토교통부 TAGO(가까운 정류소 조회), 카카오(좌표→행정구역). 기기에 저장하지 않습니다 |
| 개인 정보 — 이름 | **수집함**(카카오 로그인 시 닉네임). 목적: 앱 기능. 선택 사항: **예**. 저장하지 않고 앱 실행 중에만 사용 |
| 앱 활동 — 검색 기록 | **수집함**. 목적: 앱 기능. **기기에만 저장**되며 전송하지 않습니다 |
| 사진/동영상 | **수집 안 함** (AR은 카메라 화면을 표시만 하고 촬영·저장하지 않습니다) |
| 데이터 암호화 전송 | **예** (전부 HTTPS) |
| 데이터 삭제 요청 가능 | **예** — 앱 삭제 또는 앱 저장공간 지우기 |

> 위 표의 '공유함'은 개발자가 수집한다는 뜻이 아니라, 기능 수행을 위해 제3자
> API로 전송된다는 뜻입니다. 콘솔 문구가 헷갈리게 돼 있으니 주의하세요.
